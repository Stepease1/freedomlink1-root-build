# ✦ Freedomlink1 Proposal Submission Portal  
Sovereign Digital Institution • Governance Intake Layer

This portal provides the official interface for submitting governance proposals to the Freedomlink1 institution. All proposals must comply with the Sovereign Codex, Unified Layer bindings, and lineage continuity rules.

Proposals submitted through this portal enter the institutional governance pipeline and are validated automatically by the Proposal Validation Workflow.

---

## ✦ Submission Requirements

All proposals **must** include:

- **Title** — clear, sovereign‑grade name  
- **Summary** — concise description of intent  
- **Rationale** — justification for institutional change  
- **Codex Compliance** — clauses referenced  
- **Lineage Impact** — epoch, anchor, or seal implications  
- **Treasury Impact** — if applicable  
- **Implementation Plan** — steps required  
- **Amendment Requirements** — if modifying existing artifacts  

These requirements ensure proposals integrate cleanly into the institution.

## ✦ Submission Process

1. **Create a new file** in:  
   `docs/proposals/`

2. **Name the file** using the institutional format:  
   `Proposal_<identifier>_<short_title>.md`

3. **Add the proposal** to the proposal index:  
   `docs/proposals/index.md`

4. **Commit the proposal** with a semantic message:  
   `proposal: add <short_title>`

5. **Push to main**  
   The Proposal Validation Workflow will automatically:

   - validate metadata  
   - check required sections  
   - verify Codex compliance  
   - ensure lineage references  
   - update governance integrity  

Only validated proposals enter the governance review cycle.
